# 🎮 Top-Down RPG (Birthday Gift Project)

Welcome to the repository of our game! This is a classic top-down RPG developed entirely in the **Godot Engine**.

This project holds a special meaning for us – it was created as a unique **birthday gift for a close friend**. The game is packed with dedicated content, personal references, and inside jokes that only our friend group will understand.

## 🤝 About the Project & Collaboration

While the core game mechanics were programmed solo, creating the actual game world was a massive collaborative effort. A group of friends joined forces to fill the game with unique content. Together, we worked on:

* Writing dialogues and designing quests
* Creating maps and level design
* Packing the game with inside jokes and personal references
* Playtesting to ensure the gift was as fun as possible!

## 🧑‍💻 Developer Note (Project Context)

If you are a recruiter or another developer looking at this code, please keep in mind the context of this project:
* **Strict Deadline:** The game had a hard, non-negotiable release date (the birthday party!). 
* **Focus on Delivery:** The primary goal was to deliver a functional, feature-complete, and fun experience on time. Therefore, rapid prototyping and content implementation were prioritized over perfect code architecture or optimization.
* **100% Human-Made:** The code was written completely from scratch without the use of any AI assistants (like ChatGPT or Copilot). It's a raw, hands-on effort to create something truly personal.

## 🛠️ Technologies

* **Engine:** [Godot Engine](https://godotengine.org/)
* **Genre:** Top-Down RPG

## 🚀 How to Play

### 📥 Download the Game (Windows & macOS)
The easiest way to play the game is to download the pre-compiled official release:
1. Go to the [Releases](https://github.com/LukaszKosobucki/top-down-rpg/releases) page on GitHub.
2. Download the appropriate `.zip` file for your operating system (**Windows** or **macOS**).
3. Extract the downloaded archive and run the executable file to start your adventure!

### 🧑‍💻 For Developers (Running from Source)
